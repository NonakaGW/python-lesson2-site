# プログラミング第2回 オンライン教室

篠崎中学校チャレンジクラス「プログラミング第2回」のオンライン参加者向けサイトです。

## できること

- TechNexus利用ガイドの閲覧・保存
- 第2回授業資料の閲覧・保存
- 紙の確認テストと同じ8問へのWeb回答・自動判定

確認テストでは正解の内容を表示しません。間違えた問題は授業資料を確認して、何度でも解き直せます。

## 既存のGitHub Pagesを更新する方法

1. `python-lesson1-site` リポジトリを開きます。
2. リポジトリ直下にある古いサイト用ファイルを削除します。
3. このフォルダの中身を、リポジトリの一番上へアップロードします。
4. 変更をコミットします。
5. 数分後、次のURLで表示を確認します。

https://nonakagw.github.io/python-lesson1-site/

ビルド作業は不要です。

## ファイル構成

- `index.html`：画面の構造と確認テスト
- `styles.css`：デザインとiPad対応
- `app.mjs`：資料切り替え・画面切り替え・採点表示
- `quiz-core.mjs`：確認テストの判定処理
- `assets/tech-nexus-guide.pdf`：TechNexus利用ガイド
- `assets/lesson-2.pdf`：第2回授業資料
- `tests/`：採点処理とファイル構成のテスト
